### Features
- 🚀 **Direct One-Click APK Download**: Pulls directly from GitHub Releases.
- ⚡ **Dynamic Release Fetcher**: Always serves the latest APK version and file size via GitHub API.
- 📱 **QR Code Mobile Scanner**: Easily scan the QR code from your computer screen to download APK straight to your Android phone.
- 🎨 **Modern App Store Interface**: Apple & Google Play-inspired dark glassmorphism aesthetic.
